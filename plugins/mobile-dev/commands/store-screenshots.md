Invoke the **store-screenshots** skill and run it as a guided questionnaire for the user.

Lead with the flow, one question at a time:

1. Confirm the **app project directory** (use `$ARGUMENTS` if provided; otherwise ask), then
   explore it to understand what the app does, who it's for, and its **visual identity**
   (brand colours, typeface, personality).
2. **Brief** the user on what you found and ask the few things the code can't answer
   (audience, the single biggest reason to download, differentiators, must-highlights).
3. Propose the **screenshot plan + visual system** as text and get approval.
4. Have the user **capture** the planned app screens.
5. **Design each screenshot bespoke** to the app's brand and **render** it, iterating on the
   PNGs with the user until the set is approved.

Follow the skill's phases and DESIGN GUIDELINES exactly. Design each shot from scratch to
match this app — never fill a fixed template.

App project directory: $ARGUMENTS
